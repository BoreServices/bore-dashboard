---
title: AntiNuke Webhook
description: Prevent users from creating, modifying, or deleting too many webhooks within a configurable timeframe.
---

<Callout type="info">
  Replace ``[prefix]`` with your own prefix. Type ``@bore#6621 prefix`` to get your server prefixes, however, ``;`` is default.
</Callout>

## Enable

To enable antinuke webhook, run the following command:

```python
[prefix]antinuke webhook enable
```

<Frame>
  <img src="/img/antinuke/examples/webhook/antinuke-webhook-default.png" alt="AntiNuke Webhook Default" width="600" />
</Frame>

To set a custom threshold for how many webhook modifications trigger antinuke, pass the `--threshold` flag:

```python
[prefix]antinuke webhook enable --threshold 3 --duration 1h --punishment strip
```

&nbsp;

| Flag | Description |
|---|---|
| `--threshold` | Number of webhook modifications before antinuke triggers |
| `--duration` | Time window to count kicks within |
| `--punishment` | Action taken against the attacker: `ban`, `kick`, or `strip` |


<Frame>
  <img src="/img/antinuke/examples/webhook/antinuke-webhook-1.png" alt="AntiNuke Webhook Example" width="600" />

## Disable

To disable antinuke webhook protection, run the following command:

```python
[prefix]antinuke webhook disable
```
