---
title: AntiNuke Role
description: Prevent users from creating, modifying, or deleting too many roles within a configurable timeframe.
---

<Callout type="info">
  Replace ``[prefix]`` with your own prefix. Type ``@bore#6621 prefix`` to get your server prefixes, however, ``;`` is default.
</Callout>

## Enable

To enable antinuke role, run the following command:

```python
[prefix]antinuke role enable
```

<Frame>
  <img src="/img/antinuke/examples/role/antinuke-role-default.png" alt="AntiNuke Role Default" width="600" />
</Frame>

To set a custom threshold for how many role modifications trigger antinuke, pass the `--threshold` flag:

```python
[prefix]antinuke role enable --threshold 3 --duration 1h --punishment strip
```

&nbsp;

| Flag | Description |
|---|---|
| `--threshold` | Number of role modifications before antinuke triggers |
| `--duration` | Time window to count modifications within |
| `--punishment` | Action taken against the attacker: `ban`, `kick`, or `strip` |

<Frame>
  <img src="/img/antinuke/examples/role/antinuke-role-1.png" alt="AntiNuke Role Example" width="600" />

## Disable

To disable antinuke role, run the following command:

```python
[prefix]antinuke role disable
```
