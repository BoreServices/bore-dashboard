---
title: AntiNuke Bot
description: Prevent users from adding bots to your server.
---

<Callout type="info">
  Replace ``[prefix]`` with your own prefix. Type ``@bore#6621 prefix`` to get your server prefixes, however, ``;`` is default.
</Callout>

<Callout type="warning">
  In order to be able to add an bot to a server with this module enabled, you must have antinuke whitelist otherwise the bot will be automatically kicked.
  You are encouraged to view our [antinuke setup](/docs/antinuke/setup#antinuke-whitelist) documentation for details on whitelisting another user. 
</Callout>

## Enable

To enable antinuke bot, run the following command:

```python
[prefix]antinuke bot enable
```

  <img src="/img/antinuke/examples/antinuke-bot.png" alt="AntiNuke Bot Default" width="600" />

## Disable

```python
[prefix]antinuke bot disable
```
