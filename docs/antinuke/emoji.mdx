---
title: AntiNuke Emoji
description: Prevent users from creating, modifying, or deleting too many emojis within a configurable timeframe.
---

<Callout type="info">
  Replace ``[prefix]`` with your own prefix. Type ``@bore#6621 prefix`` to get your server prefixes, however, ``;`` is default.
</Callout>

## Enable

To enable antinuke emoji, run the following command:

```python
[prefix]antinuke emoji enable
```

<Frame>
  <img src="/img/antinuke/examples/emoji/antinuke-emoji-default.png" alt="AntiNuke Emoji Default" width="600" />
</Frame>

To set a custom threshold for how many emoji modifications trigger antinuke, pass the `--threshold` flag:

```python
[prefix]antinuke emoji enable --threshold 3 --duration 1h --punishment strip
```

&nbsp;

| Flag | Description |
|---|---|
| `--threshold` | Number of emoji modifications before antinuke triggers |
| `--duration` | Time window to count modifications within |
| `--punishment` | Action taken against the attacker: `ban`, `kick`, or `strip` |

<Frame>
  <img src="/img/antinuke/examples/emoji/antinuke-emoji-1.png" alt="AntiNuke Emoji Example" width="600" />

## Disable

To disable antinuke emoji, run the following command:

```python
[prefix]antinuke emoji disable
```
