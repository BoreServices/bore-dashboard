---
title: AntiNuke Channel
description: Prevent users from creating, modifying, or deleting too many channels within a configurable timeframe.
---

<Callout type="info">
  Replace ``[prefix]`` with your own prefix. Type ``@bore#6621 prefix`` to get your server prefixes, however, ``;`` is default.
</Callout>

## Enable

To enable antinuke channel, run the following command:

```python
[prefix]antinuke channel enable
```

<Frame>
  <img src="/img/antinuke/examples/channel/antinuke-channel-default.png" alt="AntiNuke Channel Default" width="600" />
</Frame>

To set a custom threshold for how many channel modifications trigger antinuke, pass the `--threshold` flag:

```python
[prefix]antinuke channel enable --threshold 3 --duration 1h --punishment strip
```

&nbsp;

| Flag | Description |
|---|---|
| `--threshold` | Number of channel modifications before antinuke triggers |
| `--duration` | Time window to count kicks within |
| `--punishment` | Action taken against the attacker: `ban`, `kick`, or `strip` |

<Frame>
  <img src="/img/antinuke/examples/channel/antinuke-channel-1.png" alt="AntiNuke Channel Example" width="600" />
</Frame>

## Disable

To disable antinuke channel, run the following command:

```python
[prefix]antinuke channel disable
```
