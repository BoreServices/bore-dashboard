# Introduction

  These docs are currently in **beta**, expect unfinished and not up to date documentation.

[**Evict**](/) is the all-in-one solution for seamless Discord server management — powerful, polished, and visually refined.

## What is Evict?

Evict is a feature-rich Discord bot designed to give server administrators and moderators a complete toolkit for managing their communities. From advanced moderation to music playback, anti-nuke protection to custom embeds, Evict covers every corner of server management.

## Key Features

- **Moderation** — Full suite of moderation tools -- hardban, ban, unban, timeout, untimeout, with full logging to a specified channel.
- **Anti-Nuke** — Keep your server safe with our fully customizable antinuke system -- strip, kick, or ban users for going over your specified threshold. 
- **Embeds** — Save, send, or copy rich embeds.
- **VoiceMaster** — Give users full control over their own voice channels.
- **Tickets** — Full-featured support ticket system.
- **Social** — Post notifications for YouTube, Twitch, Reddit, and more.

## Getting Started

<Callout type="info">
  Evict requires **Administrator** permissions upon inviting it. You can restrict permissions after inviting the bot.
</Callout>

1. [Invite Evict](https://discord.com/oauth2/authorize?client_id=1203514684326805524&permissions=8&integration_type=0&scope=bot) to your server.
2. View our [commands](/commands) or get [support](/support) to get started.
